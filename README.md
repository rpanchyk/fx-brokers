# FX Brokers

Повторюваний пайплайн PDF-аналітики ритейл форекс-брокерів: зведені таблиці порівняння та повні профілі за списком із `config.yml`.

Дата зрізу в звіті — **день запуску** (не задається в конфігурації). Ім’я файлу: `FxBrokers_YYYY-MM.pdf`.

## Структура

| Шлях | Призначення |
|---|---|
| `config.yml` | Брокери, пункти аналізу, мова UI, формат PDF |
| `data/brokers.yaml` | Дослідницькі дані (факти по брокерах) |
| `run.py` | Точка входу |
| `src/` | Завантаження конфігу/даних і збірка PDF |
| `requirements.txt` | Залежності (`reportlab`, `PyYAML`) |
| `FxBrokers_YYYY-MM.pdf` | Результат (у `.gitignore`) |

## Встановлення

```bash
pip install -r requirements.txt
```

Потрібен Python 3 і Unicode-шрифт: Calibri / Arial / Segoe UI (Windows) або DejaVu (Linux).

## Запуск

```bash
python run.py
python run.py --config config.yml
python run.py --as-of 2026-08        # рідко: перевизначити період вручну
python run.py --as-of 2026-08-15     # рідко: повна дата в методології
```

За замовчуванням:
- у методології — сьогоднішня дата (`YYYY-MM-DD`);
- у шапці / імені файлу — поточний місяць (`YYYY-MM`).

Помилки конфігу чи даних виводяться як `ERROR:` (код виходу 1).

## Як користуватися

1. **Список брокерів** — `brokers` у `config.yml`. `id` має збігатися з ключем у `data/brokers.yaml`. Порядок у списку = порядок у PDF.
2. **Пункти аналізу** — `points` у `config.yml`. Порядок = важливість у профілях. Видаліть або закоментуйте пункт — він зникне зі звіту.
3. **Факти** — лише `data/brokers.yaml`. Статуси: `yes` \| `no` \| `partial` (PyYAML `yes`/`no` нормалізуються автоматично).
4. **Оформлення** — блок `output` у `config.yml`:
   - `language`: `uk` (за замовчуванням) \| `en` — мова UI; нотатки в YAML лишаються українською
   - `orientation`: `portrait` \| `landscape`
   - `paper_size`: `A4` \| `A3`
   - `title`, `filename_pattern` (`{YYYY}`, `{MM}`)
5. **Новий брокер** — спочатку повний запис у `data/brokers.yaml`, потім додайте `id` у `config.yml`.
6. Після змін знову запустіть `python run.py`.

Звіт зібрано з відкритих джерел і **не є інвестиційною рекомендацією**. Умови залежать від entity і юрисдикції клієнта.
